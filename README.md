# SO-Price

Цены на предметы Stay Out (Stalker Online): минимальная стоимость на доске объявлений, где взять предмет и сколько стоит набор.

Сайт: https://montihx.github.io/so-price/

## Возможности
- 1178 предметов: оружие, обвесы, патроны, экипировка, артефакты, медицина, трофеи и прочее
- Поиск по названию (латиница тоже: `AK` найдёт «АК»), подсветка совпадений
- Вкладки «Все», «Есть на доске», «Нет объявлений»
- Сортировка по названию и по цене
- Категории: оружие, обвесы, патроны, гранаты, экипировка, медицина, артефакты, трофеи, прочее
- Два вида: списком и сеткой, как инвентарь в игре
- Ссылка на предмет: `…/so-price/#АК-103` сразу открывает его карточку
- Карточка предмета: цена и дата, как получить (где найти, у кого купить или выменять, из чего выпадает), где используется, кому продать, подходящие патроны и ремонт
- История цены: график по датам и изменение к прошлой цене; если объявлений сейчас нет — последняя известная цена
- «Где выгоднее»: продать на доске или NPC, купить на доске или у NPC
- Калькулятор: сумма по набору предметов и выручка при продаже лучшим способом; список сохраняется в браузере

## Стек
- Статический сайт на GitHub Pages: HTML, CSS, React 18 (UMD) и ES-модули, без сборки
- Данные: `data/data.json` (предметы и цены), `data/history.json` (история цен), `data/meta.json` (категории), `data/src/<id>.json` (сведения для карточки — отдельный файл на предмет)
- Иконки: `icons/<id>.webp` (сжатые) и `icons/<id>.png` (запасные), имя файла — значение `icon_local_path`

## Локальный запуск
```
python -m http.server 8000
```
и открыть http://localhost:8000. Открыть `index.html` двойным щелчком не получится: браузер не загрузит модули и данные с диска.
